# ADR-011: Only verified agents can contact talent

Status: Proposed

## Context

Fake-agent scams are the main abuse pattern on talent platforms.

## Decision

Only agents who pass verification can send contact requests. Talent accepts a request before chat opens.

## Alternatives considered

Open messaging; connection requests from any agent.

## Consequences

Safer for talent, slower growth on the agent side. Awaiting client sign-off before milestone 4. Built as described in ADR-038.
